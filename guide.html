Шаг 1. Начало работы

Что нужно сделать: Перейдите на портал Госуслуг и найдите нужную услугу.

Перейдите по ссылке: https://www.gosuslugi.ru/625124/1/form

Или задайте в поиске Госуслуг запрос: «регистрация экспертизы промышленной безопасности»

Скриншот: поиск услуги на Госуслугах

В результатах поиска выберите услугу «Ведение реестра заключений экспертизы промышленной безопасности».

Что можно сделать с помощью услуги:
  • Внести заключение в реестр
  • Получить выписку из реестра
  • Исключить заключение из реестра
  • Исправить опечатки или ошибки

Шаг 2. Выбор действия и требования

Выберите действие: Нажмите «Внести заключение экспертизы промышленной безопасности в реестр».

Что потребуется:

  • Данные организации
  • Ваши данные
  • Данные экспертной организации
  • Сведения об экспертах
  • Данные заключения ЭПБ
  • Сведения о выводах
  • Скан заключения

Срок: 1 рабочий день.

Подпись: Нужна электронная подпись.

Результат: Выписка в личном кабинете.

Шаг 3. Проверка данных организации

Данные подтягиваются из профиля Госуслуг автоматически.

1. Данные организации

Проверьте наименование, ИНН, ФИО руководителя.

2. Телефон и почта

Проверьте и при необходимости отредактируйте.

3. Юридический адрес

Подтягивается автоматически.

4. Ваши данные

Паспорт, СНИЛС, дата рождения.

5. Ответственный сотрудник

Укажите телефон и email для связи.

Шаг 4. Экспертная организация и эксперты

1. ИНН экспертной организации

Ищите в разделе «Сведения об экспертной организации».

2. Сведения об экспертах

Скриншот: выбор типа номера эксперта
Данные берите из раздела «Сведения об экспертах, принимавших участие в проведение экспертизы».

Один из трёх способов:

  • Номер квалификационного удостоверения (чаще всего)
  • Номер записи в ЕРУЛ
  • Номер удостоверения независимой оценки

Шаг 5. Данные заключения

Все данные берутся из текста экспертизы. Текст можно сократить до существенной части.

1. Наименование

Дословно с титульного листа.

2. Объект экспертизы

Из выпадающего списка.

Скриншот: поля для данных заключения

3. Наименование объекта

Из раздела «Наименование объекта экспертизы».

4. Назначение объекта

Из раздела «Назначение объекта экспертизы».

Скриншот: пример заполнения

5. Регистрационный номер ОПО

Обычно на титульном листе.

6. Выводы

Выберите «соответствует» или «не соответствует».

Скриншот: выбор вывода
Скриншот: пример заполнения выводов

Укажите регистрационный номер заключения и дату подписания.

Срок безопасной эксплуатации — необязательно.

Шаг 6. Документы и отправка

1. Заключение (PDF)

Скан с подписями эксперта и директора, заверенный печатью.

Скриншот: загрузка заключения

2. Электронная подпись (SIG)

Два файла .sig (от эксперта и директора).

Скриншот: загруженные PDF и SIG

3. Отделение Ростехнадзора

Выберите по поднадзорности вашей организации.

Скриншот: выбор отделения Ростехнадзора

4. Подписание и отправка

Проверьте файлы и подпишите заявление.

Скриншот: документы на подписание
Результат: Выписка придёт в личный кабинет в течение 1 рабочего дня.
