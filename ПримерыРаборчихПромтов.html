1
Составить тест для проверки знаний

Создай тест из 10 вопросов для проверки знаний по безопасной эксплуатации [оборудование/вид работ]. К каждому вопросу предложи 4 варианта ответа, укажи правильный и кратко объясни его. Проверяй не формальное запоминание, а понимание опасностей и правильных действий в реальных ситуациях.

2
Собрать сценарий инструктажа

Напиши сценарий инструктажа по промышленной безопасности для электрогазосварщика. Ситуация — сварка в замкнутом пространстве. В ключевых моментах предложи 2–3 варианта действий и укажи последствия каждого выбора. Используй реалистичные производственные условия.

3
Адаптировать готовый инструктаж под возрастную группу

Адаптируй прикрепленный текст инструктажа по промышленной безопасности для [профессия]. Аудитория — сотрудники 55+. Используй короткие предложения, крупный шрифт, простой язык и акцент на практические действия. Сохрани все обязательные требования исходного материала.

4
Создать обучающий чек-лист

Создай обучающий чек-лист для стропальщика с опытом работы 3 месяца. Только практика, без теории. 7 вопросов для самопроверки перед подъемом груза, ответы ДА/НЕТ. В конце добавь правило: «Хотя бы одно НЕТ — не работай, зови мастера». Объем — не более одной страницы.
